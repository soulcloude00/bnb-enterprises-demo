# B&B Enterprises — demo website

Static demo site for **B&B Enterprises (Burman and Burman Enterprises)**, a Bangalore family construction contractor (Mivan & block construction).

- Pages: Home, Projects (filterable), 3 project detail pages, Services, About, Contact, 404
- Pure HTML/CSS/JS. Pages are generated by `_build/build.py` (`python3 _build/build.py`).
- Status: **demo**. Items tagged "Placeholder" / "To confirm" / "Sample" need real information before launch. The enquiry form is front-end only and sends nothing.

## Build your vision (3D consultation configurator)
- Every "Request a consultation" button (`data-consult`) opens a full-screen overlay; it also lives at `consult.html`.
- Source: `_build/consult-src/*.js` (concatenated into `assets/js/consult.js` by `_build/build.py`), styles in `assets/css/consult.css`.
- Three.js r169 is vendored in `assets/vendor/three-0.169.0/` (MIT) and only loads when the overlay opens.
- Front-end only: nothing is submitted. The WhatsApp number (`WA_NUMBER` in `01-ui.js`) is a **placeholder**.
- 12 questions, incl. a **Design** step: 3 variants per building type (distinct massing/rooflines), with thumbnails rendered from the live 3D scene (SVG elevation fallback without WebGL).
- Look: textured PBR materials, transmission glass (high tier), HDRI reflections, ACES, soft shadows, GTAO, bloom, tilt-shift/vignette grade; Day / Golden hour / Night toggle.
- Quality tiers high/medium/low chosen per device and stepped down automatically if FPS < ~42; force one with `consult.html?q=high|medium|low`.
- Textures (ambientCG) and HDRI (Poly Haven) are CC0 and vendored in `assets/tex/` — see `assets/tex/CREDITS.txt`.
- QA scripts: `_build/qa_consult.py`, `_build/qa_extra.py`, `_build/qa_extra2.py`, `_build/qa_v2.py`, `_build/qa_v2b.py` (headless Chrome + SwiftShader).

- Sections: live project tracker, Mivan speed, safety record, before/after + time-lapse, builder testimonials, workforce, equipment & capacity, quality checks, company-profile download. Home shows a teaser of the first three.

- Company profile PDF: `python3 _build/profile.py` → `assets/docs/bnb-company-profile-SAMPLE.pdf` (+ cover thumbnail). Marked SAMPLE on every page.
- Construction progress / time-lapse photos are illustrative stock from Wikimedia Commons (not B&B sites): Biswarup Ganguly (CC BY 3.0/4.0, Forum Atmosphere, Kolkata), Saad Akhtar (CC BY 2.0), WTF Formwork (CC BY-SA 3.0). Credited on the page.
